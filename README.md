### 一、产品概述

- 多平台矩阵营销号统一管理与发布工具，支持 macOS / Windows / Linux 三平台。
- 一个账号一个独立浏览器环境（Cookie 隔离），登录态互不干扰，选项卡随时切换。
- 每账号可配独立代理，按代理自动分组运行多个浏览器引擎实例。
- 帐密与 Cookie 加密存储（AES-256-GCM + 系统钥匙串），重启自动恢复登录态。
- 掉号主动告警：后台定时检测 + 系统通知 + 短信双通道提醒。

核心价值：

- 多平台、多账号集中管理，矩阵营销分发一站完成。
- 内置隐身指纹与代理隔离，降低矩阵账号关联与封号风险。
- 支持自定义平台，不受内置平台列表限制。
- 数据全部本地加密存储，不经过第三方服务器。

### 二、功能说明

#### 账号管理

- 多账号登录态隔离（独立 BrowserContext），选项卡式工作台随时切换。
- 帐密加密存储，Cookie 加密持久化，重启自动续登。
- 账号分组管理，侧边栏按分组展示与计数。

#### 代理支持

- 每账号独立代理地址，按代理分组自动启动多个引擎实例。
- 代理出口与浏览器指纹隔离，矩阵防关联。

#### 发布能力

- 单账号发布：标题 / 正文 / 媒体路径，支持 cron 定时发布。
- 批量发布：同一内容一次分发到多个账号，逐账号结果反馈。
- 敏感词检测：广告法极限词、医疗、金融违规词库，发布前检查。

#### 平台适配

- 内置抖音适配器（扫码登录，Cookie 持久化）。
- 自定义平台：注册任意平台的创作者页 / 发布页 URL 与表单选择器，按配置自动发布。

#### 掉号提醒

- 后台每 5 分钟自动检测已打开会话，掉号即告警。
- 系统通知 + 阿里云短信（配置后）双通道提醒。
- 关闭窗口最小化到托盘，后台监控不中断。

### 三、安装与下载

从 [Releases](https://github.com/Mutantcat-Working-Group/MarketingConnect/releases) 下载对应平台安装包：

- macOS：`MarketingConnect_1.0.1024_aarch64.dmg`
- Windows：`MarketingConnect_1.0.1024_x64-setup.exe`
- Linux：`MarketingConnect_1.0.1024_amd64.deb` / `MarketingConnect-1.0.1024-1.x86_64.rpm` / `MarketingConnect_1.0.1024_amd64.AppImage`

源码自编译需 Node.js 20+、pnpm 9+、Rust 1.75+，Linux 需 `libwebkit2gtk-4.1-dev` 等 Tauri 系统依赖；推送到 main 或打 v* 标签时 GitHub Actions 自动构建三平台安装包。

### 四、快速上手

1. 启动引擎：顶栏点击「启动引擎」。
2. 新增账号：左侧「新增账号」，选择平台、填写帐密与代理（可填分组）。
3. 打开会话：账号工作台点击「打开会话」。
4. 手动登录：查看页面截图，扫码或输入帐密完成登录。
5. 保存 Cookie：登录成功后点击「保存 Cookie」持久化会话。
6. 创建发布任务：填写内容（可先「检测敏感词」），可选 cron 表达式定时发布。
7. 批量发布：顶栏「批量发布」，勾选多个账号一次分发同一内容。
8. 掉号提醒：后台自动检测，掉号时系统通知 + 短信提醒。
9. 关闭窗口即最小化到托盘，托盘左键单击恢复窗口。

### 五、技术栈

- 桌面外壳：Tauri 2（Rust）
- 前端：Vue 3 + TypeScript + Vite
- 浏览器引擎：[Obscura](https://github.com/h4ckf0r0day/obscura)（Rust 无头浏览器，内置隐身反指纹）
- CDP 驱动：chromiumoxide
- 存储：SQLite + AES-256-GCM 加密
- 调度：tokio-cron-scheduler
- 短信：阿里云短信服务
